Name a glyph and paint it. There is no asset source to register:

```rust
use ui::icons::{self, glyph};

icons::icon(glyph::Search).size(px(16.0)).text_color(theme.text_muted)
```

`icon` returns a gpui `Svg`, so it colors with `text_color` and sizes like any element.

## The set is Lucide's

Modules are Lucide's categories, constants are Lucide's names in Lucide's own casing — `arrows::ArrowBigDown`, spelled as lucide.dev spells it — and both are generated by `crates/icons/build.rs` from a pinned release — there is no curated list in this repository to drift from upstream. `glyph` holds every enabled icon; a category re-exports the ones Lucide files under it, so `arrows::Play` and `multimedia::Play` are one constant and one copy of the bytes.

The build script downloads that release once, rewrites each drawing into the document gpui paints, and writes both the assets and the module tree. Neither is checked in, and both are bundled into the published crate, so a consumer building from crates.io never runs the download and the crate still works offline, under `cargo vendor` and on docs.rs.

Bumping the pinned version is the upgrade, and the diff says exactly which glyphs upstream redrew — which is the failure the previous set was built to avoid and did not: it sat two years behind, painting a `play` triangle Lucide had already replaced.

Lucide is ISC-licensed and asks for no attribution in a shipped binary.

## Paying for what you paint

A constant *is* the SVG, not a path into an asset source, so an icon a binary never names is dropped by the linker. That is finer than any feature can be and needs no opting in.

Categories are cargo features on top of it, one per Lucide category, named as Lucide names them. Nothing is on by default:

```toml
bezel-icons = { version = "0.1", features = ["arrows", "navigation"] }
```

`full` is all 42. Cargo unions features across a graph, so a category a dependency turns on is one you cannot turn off — `ui` needs `arrows`, `notifications` and `text` for its own components, and those three are the floor for anything depending on it.

`icons::CATEGORIES` is every enabled category and its `(name, svg)` pairs, for building an icon browser. Naming it pins the whole enabled set — which is why the gallery previews a sample instead, and why an app that only paints icons never mentions it.

## Solid twins

Lucide draws one weight. `icons::solid` fills the outline instead of reaching for a second drawing — filled *and* stroked, so the outer edge lands exactly where `icons::icon` puts it and a control swapping between them does not jump.
